# Experiments

This folder preserves exploratory implementations and research notebooks separately from the primary FastAPI/WebSocket application.

## Contents

- `notebooks/` — audio-to-audio, speech model comparison, end-to-end automation, and voice-cloning experiments.
- `socketio-variant/` — an alternative Socket.IO transport implementation.
- `http-api/` — an earlier HTTP API prototype.
- `openapi-client/` — an OpenAPI-oriented client/server experiment.
- `websocket-client/` — an alternate WebSocket client and speech generation experiment.
- `standalone-prototypes/` — earlier standalone speech, grammar, recording, and model-loading scripts.

These experiments are retained as research artifacts. They may have separate dependencies, external model requirements, and configuration assumptions; they are not part of the main application startup path.

# GitHub publication checklist

- [ ] Confirm you have permission to publish all source code and experiment notebooks.
- [ ] Review notebooks for embedded credentials, private paths, and personal data.
- [ ] Create `.env` locally from `.env.example`; never commit API keys.
- [ ] Do not upload real user recordings, transcripts, or generated audio.
- [ ] Verify the main application in a fresh virtual environment.
- [ ] Add a license only if you own or have permission to license the code.
